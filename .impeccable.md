## Design Context

### Users
Personal use. Individual tracking personal tasks and projects.

### Brand Personality
Minimal, clean, functional. Notion-inspired — stripped back, content-first, nothing decorative.

### Aesthetic Direction
- Theme: Light and dark modes, clean aesthetic
- Philosophy: Less is more. Every element must justify its existence
- Reference: Notion — minimal, white-space driven, typography-focused

### Design Principles
1. Content over chrome — UI recedes, content dominates
2. Subtle polish — no decorative elements, refined interactions only
3. Neutral palette — tinted neutrals, minimal color beyond functional use
4. Monospace for metadata — dates, tags, labels use monospace for technical feel
